# 需求討論摘要｜先討論、後生成

下表是本次 Wiki 建置的需求決策摘要，用來確認建檔規則前已界定作業範圍；不是逐字訪談稿。

| 先釐清的問題 | 本次決定 |
|---|---|
| Wiki 給誰看？ | 第一次接觸 AI Agents 的大學生。 |
| 想學會什麼？ | 說出 Agent 的基本構成、運作循環、工具使用及適用範圍。 |
| 要哪些頁型？ | 概念頁、研究/文件來源頁、索引、ingest log、流程/反思。 |
| 語言與產物？ | 繁體中文 Markdown Wiki + 10 張 HTML 簡報。 |
| 來源範圍？ | 五份 AI Agents 的官方文件及原始研究論文；課堂 PDF 不列入知識來源。 |
| 引用要多細？ | 每頁有 `[S#]`，原始來源 URL 列於來源表；研究結論不泛化成普遍保證。 |
| 來源觀點不同怎麼辦？ | 區分研究論文、官方文件、框架文件的語境；明示概念模型/工具產品的差異。 |
| ingest 批次？ | 逐筆整理，共 5 份，完成引用與限制記錄後更新 log。 |
| 輸出教學範圍？ | Agent 是什麼、怎麼使用工具、ReAct 循環、工作流/Agent 差別、何時使用與如何檢查。 |
| lint 要檢查什麼？ | 五筆來源、每頁引用、主張可回查、10 頁、內部連結與瀏覽控制。 |
| 何時人工介入或停下？ | 來源不足/定義不同時標註；不猜；簡報最多修 3 輪。 |

以上摘要落實到 `AGENTS.md`、`raw/` 和 `wiki/index.md` 後，才產生知識頁與簡報。
