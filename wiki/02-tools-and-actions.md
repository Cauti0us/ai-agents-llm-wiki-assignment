# 工具呼叫與外部行動

## 工具不是「模型知道答案」
工具是一個系統提供給模型使用的外部能力。模型可以提出工具名稱/參數，runtime 執行後把結果回傳；工具實際能做什麼由其介面和權限決定。[S1][S3]

## Tool calling 的基本輪次
1. 模型讀取任務與可用工具說明。
2. 模型決定是否呼叫工具，產生結構化參數。
3. runtime 驗證並執行呼叫。
4. 工具結果回到上下文，模型再產生下一步或回覆。[S3]

## Toolformer 與一般 Agent 不同
Toolformer 是研究訓練方法：模型學何時呼叫 API、傳哪些參數、如何用結果。它有助理解工具選擇問題，但不能直接等同現成 Agent 產品的 API 或控制層。[S5]

## 例子：查詢課表
若 Agent 有「搜尋校務系統」工具，可以呼叫查詢，再把工具回傳的課表整理成回答。它不應宣稱已改課或送出申請，除非真的有相應工具並收到成功結果。
