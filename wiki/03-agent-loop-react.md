# Agent 運作循環：ReAct 的教學模型

## 循環
**任務 → 推進下一步 → 行動/工具呼叫 → 觀察結果 → 更新下一步 → 完成或停止。** Agent 的步驟可因工具結果而變化，因此控制層要管理狀態、錯誤和結束條件。[S1][S2]

## ReAct
ReAct 論文研究 reasoning traces 與 task-specific actions 交錯生成，讓模型可從知識庫/環境取資料，根據觀察修正後續計畫。可用「行動—觀察—更新」做入門示意。[S4]

## 範例：找出最近的圖書館營業時間
- **任務**：查今晚是否開館。
- **行動**：呼叫網路搜尋工具。
- **觀察**：得到官方頁面與營業時間。
- **更新**：比對今天星期幾和特殊公告；若不一致，再查官方公告。
- **停止**：找到可回查的官方資訊，或回報未能確認。

此範例是教學用流程，不是 ReAct 論文中實驗案例。論文 benchmark 結果只代表其評測設定，不能直接當作所有 Agent 的保證。[S4]
