# AI Agent 基本概念

## Agent 是什麼？
在本 Wiki 中，Agent 指以 LLM 為核心、能推進多步任務，並可使用工具或環境回饋來決定下一步的系統。OpenAI 文件提到 agents 能使用工具完成任務並在步驟間維持上下文；Anthropic 將自主決策流程的系統與固定 workflow 作出區分。[S1][S2]

## 和一般問答的差別
一般問答通常一次收到輸入並回覆；Agent 還可能選工具、交給工具執行、接收觀察結果，再決定是否繼續。工具回覆是環境結果，仍需檢查是否有用、是否符合任務。[S1][S4]

## 常見組成
- **模型**：理解任務並提出回應/工具呼叫。
- **指令與目標**：定義範圍和完成條件。
- **工具**：可執行的明確能力，例如搜尋或計算。
- **狀態/上下文**：記住任務進度及必要回傳。
- **控制與停止規則**：何時繼續、交回人類或結束。[S1][S2][S3]
